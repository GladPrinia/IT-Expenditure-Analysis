# IT Expenditure Analysis Dashboard (Power BI)

## 📌 Project Overview

This project focuses on analyzing **IT expenditure** across different **business areas, regions, and cost categories** using **Power BI**.
The goal is to build an **interactive dashboard** that provides transparency into **actual vs. forecast vs. planned IT costs**, helping stakeholders identify **overspending, underutilization, and budget alignment** across business units and geographies.

---

## 🎯 Objectives

The analysis aims to answer:

* How are IT costs distributed across **functions, regions, and cost elements**?
* What is the **variance between actual, forecasted, and planned IT spend**?
* Which **cost drivers** (labor, shared services, planning, etc.) impact IT spending the most?

---

## ⚙️ Project Implementation

### 1. **Data Preparation**

* Load and transform Excel dataset into Power BI.
* Standardize field names for consistency.
* Handle missing values (e.g., blank actuals, forecasts, or plan fields).
* Format dates and categorize fields (region, IT area, business unit, etc.).

### 2. **Cost Analysis**

* Calculate **total and category-level IT spend** for actuals, forecast, and plan.
* Compute **variance metrics** (e.g., Actual vs. Plan, Forecast vs. Plan).
* Analyze **trends over time** and across regions/IT sub-areas.

### 3. **Category & Departmental Drilldowns**

* Segment costs by **IT Area, Business Area, and Cost Element Group**.
* Identify **departments or regions** that deviate most from the plan.
* Compare **internal labor vs. shared services** cost patterns.

### 4. **Dashboard Creation**

* Build an **interactive Power BI dashboard** with slicers for **region, department, and month**.
* Use **bar/column charts** for variance and trend analysis.
* Display **KPIs and cards** for total budget vs. actual/forecast.
* Include **tree maps or pie charts** for cost distribution by subgroups.

---

## 📊 Dashboard Features

* **Interactive filters (slicers)** → Region, Department, Month.
* **KPI Cards** → Budget vs. Actual/Forecast.
* **Variance Tracking** → Actual vs. Plan, Forecast vs. Plan.
* **Visualizations** →

  * Bar/Column charts (cost trends & variance).
  * Tree maps/Pie charts (cost distribution).
  * Drilldowns (IT Area → Business Unit → Cost Element).

## 🚀 Tech Stack
